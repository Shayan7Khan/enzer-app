# Enzer App

**Enzer** is a gamified pre-registration app designed to drive app installs through referrals, helping build a large early-adopter community before launch.  

---

## MVP Features

- Drive installs via invitations from users  
- Capture and track early adopters  
- Incentivize sharing through simple gamification  
- Provide founders with insights via a lightweight admin dashboard  

---

## Goal

Enzer’s mission is to grow an engaged early user base, encourage sharing, and provide visibility into user growth, all before the full app launch.
